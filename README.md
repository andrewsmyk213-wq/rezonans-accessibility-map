# rezonans-accessibility-map
Accessible city navigation and interactive accessibility map for Chernivtsi, Ukraine. Developed by Team Rezonans for Chernivtsi Open Data Hackathon 3.0.

# Резонанс · Доступні Чернівці — Public Beta

Mobile-first карта доступності міста на базі відкритих геоданих.

- Запуск локально: `python3 server.py --port 8080`, відкрити `http://localhost:8080`.
- Деплой на Render: див. **[DEPLOY.md](DEPLOY.md)**. `render.yaml` знаходиться в корені репозиторію.
- Ключ маршрутизації `ORS_API_KEY` передавайте тільки як environment variable.
- `data/places.geojson` збережено без змін; окремо наявна датована резервна вибірка OSM у `data/osm_snapshot.geojson`. Вона не є польовою перевіркою.
- Повідомлення про помилки у публічній бета-версії вимкнено, доки не налаштоване постійне сховище з модерацією.
- Ця версія не гарантує безбар'єрність маршрутів. Відкриті дані можуть бути неповними.

## Версія 2.2

Застосунок показує резервну вибірку 157 названих точкових об’єктів OpenStreetMap від 30.10.2026 та запитує `/api/osm` для оновлення. Сервер отримує названі об’єкти з тегами доступності, медичні заклади, установи, магазини та зупинки через Overpass у прямокутній вибірці центральної частини Чернівців. Це не адміністративна межа міста. Успішна відповідь кешується на 4 години в пам'яті процесу; після перезапуску кеш очищується. Дані надані учасниками [OpenStreetMap](https://www.openstreetmap.org/copyright) за ліцензією ODbL і не є незалежною польовою перевіркою. Для використання похідних баз перевірте зобов'язання ODbL.

Державні набори і міський геопортал не підключені до автоматичного завантаження на Render. Реальні дані можна імпортувати вручну як GeoJSON; регулярна синхронізація потребує окремого налаштування й перевірки джерел. Чернетки повідомлень залишаються в браузері й нікуди не надсилаються. `ORS_API_KEY` необов'язковий та налаштовується лише на сервері.

Перевірки: `python3 -m unittest tests/test_osm.py` та `node tests/test_frontend.js`. Браузерний тест `tests/browser_v22.js` потребує Node.js Playwright і Chromium; існуючий `tests/smoke_test.py` потребує Python Playwright і Chromium.

Сценарій виступу: [DEMO_GUIDE.md](DEMO_GUIDE.md). Демонстрація маршрутизації використовує умовний граф та не показує реальний маршрут.

Категорії міських місць включають їжу, магазини, здоров’я, транспорт, послуги, культуру й відпочинок. Об’єкт не вилучається через відсутність тегів доступності. Резервний набір є історичною вибіркою, а не повним каталогом міста. Фотографії завантажуються лише за посиланнями на Wikimedia Commons або Wikidata, які є в тегах об’єкта, із зазначенням автора та ліцензії; якщо фото чи провайдер недоступні, показується заглушка.
