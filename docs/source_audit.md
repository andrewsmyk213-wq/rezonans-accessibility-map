# Перевірка джерел — 31.10.2026

Цей файл та `data_coverage.json` є звітами для розробників; Python-сервер не публікує каталог docs через HTTP.

| Джерело | Перевірено | Чому дані не імпортовано в реліз |
|---|---|---|
| [Моніторинг фізичного оточення](https://data.gov.ua/dataset/38997a1f-2e86-4bd7-9054-cd9cd206d825) | Офіційна сторінка, GeoJSON, поля `title`, `updateDate`, `ratingAuthority`, `categories[].criteria[].id/value`; обмежений запит HTTP 206 | Значення criteria потребують перевіреного словника формулювань. `rating` не перетворюється на wheelchair=yes. Повний набір не імпортовано. |
| [Реєстр ЦНАП](https://data.gov.ua/dataset/0b5b492d-cf84-4444-9997-3fa3d5d40758) | Повний JSON: 167 записів, 5 із назвою населеного пункту Чернівці; `idf`, `Lat`, `Long`, `unobstructedEntranceOrRamp`, `stairsWithHandrails`, `equippedSanitaryRoom` | Три записи мають ідентичні координати, два з них без адреси. «Вхід без перешкод АБО пандус» не підтверджує пандус; поручні не підтверджують відсутність сходів, обладнана санітарна кімната не тотожна доступній вбиральні. Не знайдено підтвердженого точного збігу з OSM. |
| [Реєстр бібліотек](https://data.gov.ua/dataset/21640874-5362-4dc3-a2b2-26c6dfec6d6a) | Повний JSON: 360 записів, 17 у Чернівцях; адреси, `registrationNumber`, `barrierFreeAccess` | Немає координат. Загальна характеристика barrierFreeAccess не доводить наявності кожного елемента. Без точного збігу назви та адреси з наявною точкою не виконується географічне об’єднання. |
| [Міські будівлі](https://data.gov.ua/dataset/c1a9b0fe-a9b9-4a9d-a150-831f7bbe86bf) | Офіційна сторінка, CSV HTTP 206; `identifier`, `date`, `buildingName`, адресні поля | У перевіреній схемі немає координат або прямих ознак wheelchair/ramp. Норми є окремим ресурсом: необхідний перевірений зв’язок, а не припущення з факту наявності будівлі. На сторінці набір позначено як неоновлений. |

API package_show повертав HTTP 403; прямі ресурси JSON/CSV вдалося прочитати. Це не доказ працездатності старого автоматичного збирача. Періодичний збирач не запускався, жоден dataset не перезаписувався.

Нових офіційних записів або атрибутів у продукт не імпортовано. Перед наступним імпортом необхідні точні стабільні ідентифікатори або узгоджені назва, адреса й місцезнаходження. Відстань сама по собі не є критерієм злиття. Для кожного атрибута слід зберігати source URL та дату спостереження; дата публікації/отримання не замінює дату фізичної перевірки.
