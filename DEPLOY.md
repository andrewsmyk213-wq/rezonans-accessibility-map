# Резонанс — деплой на Render

Цей пакет підготовлено для публічного **пілотного** запуску. Без створеного GitLab/GitHub-репозиторію та авторизації в Render сам публічний деплой не відбудеться.

## Варіант 1: через GitLab (рекомендовано)

1. У GitLab створіть **порожній** проєкт `rezonans-accessibility-map`. Не додавайте README на етапі створення.
2. Розпакуйте архів і перейдіть до папки `rezonans_render_ready`.
3. Виконайте команди нижче, підставивши свій URL репозиторію з кнопки GitLab **Code → Clone with HTTPS**:

```bash
cd rezonans_render_ready
git init
git add .
git commit -m "Prepare Rezonans public beta"
git branch -M main
git remote add origin ВАШ_URL_РЕПОЗИТОРІЮ
git push -u origin main
```

4. Відкрийте https://dashboard.render.com/ → **New → Blueprint**; підключіть GitLab (або GitHub) та оберіть репозиторій.
5. Render прочитає `render.yaml`. Перевірте: `Web Service`, `Python`, назва `rezonans-accessibility-map`, регіон `Frankfurt`, план `Free`.
6. Підтвердіть створення. Після успішного деплою відкрийте URL, який показав Render (наприклад, `https://...onrender.com`) і перевірте `/api/health`.
7. Якщо у вас є особистий ключ OpenRouteService, налаштуйте його як **Environment Variable** `ORS_API_KEY` у Render Dashboard. Не публікуйте ключ у Git або листуванні. Без нього маршрутизація лишається відключеною.

> Альтернативно створіть **Web Service**, якщо не використовуєте Blueprint. Параметри: Build Command `python3 -m compileall -q server.py scripts`; Start Command `python3 server.py --host 0.0.0.0 --port $PORT`; Health Check Path `/api/health`.

## Обов'язковий тест перед показом

- Відкрийте головну сторінку з телефона через HTTPS.
- Перевірте переміщення карти та відображення OpenStreetMap.
- Відкрийте `https://ВАШ-ДОМЕН/api/health`. Повинно бути `status: ok`.
- Перейдіть у «Відкриті дані». Якщо 0 записів, карта ще **не наповнена реальними закладами**. Не видавайте її за готову базу міста.
- Перевірте, що `https://ВАШ-ДОМЕН/server.py` і `/data/reports_pending.jsonl` повертають 404.
- Якщо маршрутизація ввімкнена, протестуйте її на справжніх точках. Результат є кандидатом, не гарантовано безбар'єрним шляхом.

## Дані

`data/places.geojson` наразі порожній. Для публікації реальних точок **спочатку** запустіть збирач локально:

```bash
python3 scripts/sync.py --refresh
```

Перевірте `data/sync_status.json`, `scripts/output/summary.json`, коректність координат, назви, дату і ліцензію джерел. Лише після ручної перевірки зробіть `git add data/places.geojson data/sync_status.json && git commit -m "Update verified source records" && git push`. Render автоматично задеплоїть нові дані.

**Під час першого деплою регулярна синхронізація на Render НЕ працює.** Її потрібно окремо налаштовувати як cron/job зі сховищем та валідацією. Не слід стверджувати, що 4 сайти вже автоматично синхронізуються.

## Безпека та обмеження

- Сервер віддає лише дозволені публічні файли. Вихідний код серверної частини, сирі файли й чернетки повідомлень через HTTP недоступні.
- Публічний прийом повідомлень **вимкнений** за замовчуванням. На безкоштовному Render диск тимчасовий; дані після зупинки/деплою зникнуть. Для ввімкнення спочатку створіть **справді постійне** сховище й систему модерації.
- На Render Free сервіс засинає після 15 хвилин без активності, а запуск може зайняти приблизно хвилину. Відкрийте вебзастосунок незадовго до захисту.
- Статичні файли й Leaflet можуть використовувати CDN; тайли OpenStreetMap завантажуються через мережу. Виконуйте [політику використання OSM tiles](https://operations.osmfoundation.org/policies/tiles/), зберігайте атрибуцію та не кешуйте всю карту для офлайну.
- Це публічна **бета-версія**, не підтверджений сервіс безпечної навігації. Застосунок не повинен гарантувати прохідність неперевірених маршрутів.
